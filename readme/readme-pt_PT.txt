== Description ==
Meep AI Translator é uma solução de tradução com IA para WordPress. Traduza as suas páginas Elementor facilmente com Polylang utilizando o motor de tradução avançado da OpenAI.

**Funcionalidades:**
– Tradução com um clique para páginas Elementor
– Integração Polylang (versões gratuita e Pro suportadas)
– Traduções alimentadas por OpenAI para resultados naturais e contextuais
– 1.800 palavras por semana incluídas grátis
– Interface de administração limpa sem interferência do Elementor
– Painel com análises de utilização

**Como funciona:**
1. Selecione a sua página Elementor
2. Escolha o(s) idioma(s) de destino
3. Clique em traduzir - a IA faz o resto!

Uma versão PRO com limites de palavras mais altos está disponível em [meeptech.com](https://meeptech.com/products/ai-translator-for-elementor-polylang/).

== Installation ==
1. Carregue a pasta do plugin para `/wp-content/plugins/` ou instale através do ecrã de Plugins do WordPress.
2. Ative o plugin através do menu 'Plugins' no WordPress.
3. Configure os seus idiomas com uma destas opções:
   - **Integrado (Recomendado):** Use o sistema de idiomas integrado do plugin — sem necessidade de plugins adicionais
   - **Polylang:** Vá a Idiomas → separador Idiomas → Adicionar idiomas
   - **WPML:** Vá a WPML → Idiomas → Adicionar idiomas e configurar
4. Navegue até à página do plugin AI Translator.
5. Comece a traduzir as suas páginas Elementor!

== Frequently Asked Questions ==
= Quantas palavras posso traduzir gratuitamente? =
A versão gratuita inclui 1.800 palavras por semana. Após atingir o limite, há um período de espera semanal.

= É necessário Elementor Pro? =
Não. Funciona com Elementor gratuito e Elementor Pro.

= É necessário Polylang Pro? =
Não. Suporta tanto Polylang gratuito como Polylang Pro.

= Qual fornecedor de IA é utilizado? =
OpenAI através da nossa API de tradução segura. Tratamos de toda a comunicação da API para garantir segurança e fiabilidade.

= Isto modificará o meu conteúdo existente? =
Não. As traduções são aplicadas a cópias traduzidas no idioma de destino. O seu conteúdo original permanece inalterado.

= O que acontece quando atinjo o meu limite de palavras? =
Terá de esperar pela reposição semanal, ou atualizar para um plano PRO para limites mais altos sem períodos de espera.

= Como posso verificar quantas palavras me restam? =
Visite AI Translator → Painel para ver a sua utilização atual e palavras restantes.

== Privacy & Data Collection ==

Este plugin liga-se à nossa API de tradução em meeptech.com para processar traduções e rastrear a utilização.

= Que dados são recolhidos: =
✅ O URL do seu website (para autenticação do serviço e rastreamento de utilização)
✅ Contagens de palavras e pares de idiomas (para aplicação de limites do plano)

= Que dados NÃO são recolhidos: =
❌ O seu conteúdo traduzido não é armazenado (apenas enviado para OpenAI para processamento)
❌ Informações pessoais ou endereços de email
❌ Dados de utilizadores ou visitantes
