== Description ==
Meep AI Translator ist eine KI-Übersetzungslösung für WordPress. Übersetzen Sie Ihre Elementor-Seiten nahtlos mit Polylang unter Verwendung der fortschrittlichen Übersetzungs-Engine von OpenAI.

**Funktionen:**
– Ein-Klick-Übersetzung für Elementor-Seiten
– Polylang-Integration (kostenlose und Pro-Versionen unterstützt)
– OpenAI-gestützte Übersetzungen für natürliche, kontextbezogene Ergebnisse
– 1.800 Wörter pro Woche kostenlos enthalten
– Saubere Admin-Oberfläche ohne Elementor-Störungen
– Dashboard mit Nutzungsanalysen

**So funktioniert es:**
1. Wählen Sie Ihre Elementor-Seite
2. Wählen Sie die Zielsprache(n)
3. Klicken Sie auf Übersetzen – die KI erledigt den Rest!

Eine PRO-Version mit höheren Wortlimits ist auf [meeptech.com](https://meeptech.com/products/ai-translator-for-elementor-polylang/) verfügbar.

== Installation ==
1. Laden Sie den Plugin-Ordner nach `/wp-content/plugins/` hoch oder installieren Sie über den WordPress-Plugin-Bildschirm.
2. Aktivieren Sie das Plugin über den Menüpunkt „Plugins" in WordPress.
3. Richten Sie Ihre Sprachen mit einer dieser Optionen ein:
   - **Integriert (Empfohlen):** Verwenden Sie das integrierte Sprachsystem des Plugins — keine zusätzlichen Plugins erforderlich
   - **Polylang:** Gehen Sie zu Sprachen → Sprachen-Tab → Sprachen hinzufügen
   - **WPML:** Gehen Sie zu WPML → Sprachen → Sprachen hinzufügen und konfigurieren
4. Navigieren Sie zur AI Translator Plugin-Seite.
5. Beginnen Sie mit der Übersetzung Ihrer Elementor-Seiten!

== Frequently Asked Questions ==
= Wie viele Wörter kann ich kostenlos übersetzen? =
Die kostenlose Version enthält 1.800 Wörter pro Woche. Nach Erreichen des Limits gibt es eine wöchentliche Abkühlphase.

= Wird Elementor Pro benötigt? =
Nein. Es funktioniert mit Elementor Free und Elementor Pro.

= Wird Polylang Pro benötigt? =
Nein. Es unterstützt sowohl Polylang Free als auch Polylang Pro.

= Welcher KI-Anbieter wird verwendet? =
OpenAI über unsere sichere Übersetzungs-API. Wir kümmern uns um die gesamte API-Kommunikation für Sicherheit und Zuverlässigkeit.

= Wird mein bestehender Inhalt geändert? =
Nein. Übersetzungen werden auf übersetzte Kopien in der Zielsprache angewendet. Ihr Originalinhalt bleibt unverändert.

= Was passiert, wenn ich mein Wortlimit erreiche? =
Sie müssen auf das wöchentliche Zurücksetzen warten oder auf einen PRO-Plan upgraden für höhere Limits ohne Wartezeiten.

= Wie kann ich meine verbleibenden Wörter überprüfen? =
Besuchen Sie AI Translator → Dashboard, um Ihre aktuelle Nutzung und verbleibende Wörter zu sehen.

== Privacy & Data Collection ==

Dieses Plugin verbindet sich mit unserer Übersetzungs-API auf meeptech.com zur Verarbeitung von Übersetzungen und Nutzungsverfolgung.

= Welche Daten werden erfasst: =
✅ Ihre Website-URL (für Service-Authentifizierung und Nutzungsverfolgung)
✅ Wortanzahl und Sprachpaare (für Plan-Limit-Durchsetzung)

= Welche Daten werden NICHT erfasst: =
❌ Ihr übersetzter Inhalt wird nicht gespeichert (wird nur zur Verarbeitung an OpenAI gesendet)
❌ Persönliche Informationen oder E-Mail-Adressen
