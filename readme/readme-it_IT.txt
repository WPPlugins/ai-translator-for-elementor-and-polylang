== Description ==
Meep AI Translator è una soluzione di traduzione AI per WordPress. Traduci le tue pagine Elementor senza problemi con Polylang utilizzando il motore di traduzione avanzato di OpenAI.

**Caratteristiche:**
– Traduzione con un clic per pagine Elementor
– Integrazione Polylang (versioni gratuite e Pro supportate)
– Traduzioni alimentate da OpenAI per risultati naturali e contestuali
– 1.800 parole a settimana incluse gratis
– Interfaccia admin pulita senza interferenze di Elementor
– Dashboard con analisi dell'utilizzo

**Come funziona:**
1. Seleziona la tua pagina Elementor
2. Scegli la/le lingua/e di destinazione
3. Clicca traduci - l'IA fa il resto!

Una versione PRO con limiti di parole più alti è disponibile su [meeptech.com](https://meeptech.com/products/ai-translator-for-elementor-polylang/).

== Installation ==
1. Carica la cartella del plugin in `/wp-content/plugins/` o installa tramite la schermata Plugin di WordPress.
2. Attiva il plugin tramite il menu "Plugin" in WordPress.
3. Configura le tue lingue con una di queste opzioni:
   - **Integrato (Consigliato):** Usa il sistema di lingue integrato del plugin — nessun plugin aggiuntivo necessario
   - **Polylang:** Vai a Lingue → scheda Lingue → Aggiungi lingue
   - **WPML:** Vai a WPML → Lingue → Aggiungi lingue e configura
4. Naviga alla pagina del plugin AI Translator.
5. Inizia a tradurre le tue pagine Elementor!

== Frequently Asked Questions ==
= Quante parole posso tradurre gratis? =
La versione gratuita include 1.800 parole a settimana. Dopo aver raggiunto il limite, c'è un periodo di attesa settimanale.

= È richiesto Elementor Pro? =
No. Funziona con Elementor gratuito ed Elementor Pro.

= È richiesto Polylang Pro? =
No. Supporta sia Polylang gratuito che Polylang Pro.

= Quale provider AI viene utilizzato? =
OpenAI tramite la nostra API di traduzione sicura. Gestiamo tutte le comunicazioni API per garantire sicurezza e affidabilità.

= Questo modificherà il mio contenuto esistente? =
No. Le traduzioni vengono applicate a copie tradotte nella lingua di destinazione. Il tuo contenuto originale rimane invariato.

= Cosa succede quando raggiungo il mio limite di parole? =
Dovrai aspettare il reset settimanale, o passare a un piano PRO per limiti più alti senza periodi di attesa.

= Come posso controllare quante parole mi rimangono? =
Visita AI Translator → Dashboard per vedere il tuo utilizzo attuale e le parole rimanenti.

== Privacy & Data Collection ==

Questo plugin si connette alla nostra API di traduzione su meeptech.com per elaborare traduzioni e tracciare l'utilizzo.

= Quali dati vengono raccolti: =
✅ L'URL del tuo sito web (per autenticazione del servizio e tracciamento dell'utilizzo)
✅ Conteggio parole e coppie di lingue (per applicazione limiti del piano)

= Quali dati NON vengono raccolti: =
❌ Il tuo contenuto tradotto non viene memorizzato (viene solo inviato a OpenAI per l'elaborazione)
❌ Informazioni personali o indirizzi email
❌ Dati di utenti o visitatori
