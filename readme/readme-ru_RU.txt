== Description ==
AI Translator for Elementor and Polylang — это решение для AI-перевода в WordPress. Легко переводите страницы Elementor с помощью Polylang, используя передовой движок перевода OpenAI.

**Возможности:**
– Перевод страниц Elementor в один клик
– Интеграция с Polylang (поддержка бесплатной и Pro версий)
– Переводы на основе OpenAI для естественных, контекстных результатов
– 1 800 слов в неделю бесплатно
– Чистый интерфейс администратора
– Панель управления с аналитикой использования

**Как это работает:**
1. Выберите страницу Elementor
2. Выберите целевой язык(и)
3. Нажмите перевести — ИИ сделает всё остальное!

PRO версия с увеличенными лимитами слов доступна на [meeptech.com](https://meeptech.com/products/ai-translator-for-elementor-polylang/).

== Installation ==
1. Загрузите папку плагина в `/wp-content/plugins/` или установите через экран плагинов WordPress.
2. Активируйте плагин через меню «Плагины» в WordPress.
3. Добавьте нужные языки в настройках Polylang (Языки → Языки).
4. Перейдите на страницу плагина AI Translator.
5. Начните переводить страницы Elementor!

== Frequently Asked Questions ==
= Сколько слов можно перевести бесплатно? =
Бесплатная версия включает 1 800 слов в неделю. После достижения лимита требуется недельный период ожидания.

= Требуется ли Elementor Pro? =
Нет. Работает с бесплатным Elementor и Elementor Pro.

= Требуется ли Polylang Pro? =
Нет. Поддерживает бесплатный Polylang и Polylang Pro.

= Какой AI-провайдер используется? =
OpenAI через наш защищённый API перевода. Мы обеспечиваем безопасность и надёжность всех API-коммуникаций.

= Изменит ли это мой существующий контент? =
Нет. Переводы применяются к переведённым копиям на целевом языке. Ваш оригинальный контент остаётся неизменным.

= Что происходит при достижении лимита слов? =
Нужно дождаться еженедельного сброса или перейти на PRO план для увеличенных лимитов без периодов ожидания.

= Как проверить оставшиеся слова? =
Перейдите в AI Translator → Панель управления для просмотра текущего использования и оставшихся слов.
