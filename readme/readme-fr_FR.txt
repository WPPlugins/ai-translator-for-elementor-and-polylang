== Description ==
Meep AI Translator est une solution de traduction IA pour WordPress. Traduisez vos pages Elementor facilement avec Polylang en utilisant le moteur de traduction avancé d'OpenAI.

**Fonctionnalités :**
– Traduction en un clic pour les pages Elementor
– Intégration Polylang (versions gratuite et Pro supportées)
– Traductions alimentées par OpenAI pour des résultats naturels et contextuels
– 1 800 mots par semaine inclus gratuitement
– Interface d'administration propre sans interférence d'Elementor
– Tableau de bord avec analyses d'utilisation

**Comment ça marche :**
1. Sélectionnez votre page Elementor
2. Choisissez la/les langue(s) cible(s)
3. Cliquez sur traduire - l'IA fait le reste !

Une version PRO avec des limites de mots plus élevées est disponible sur [meeptech.com](https://meeptech.com/products/ai-translator-for-elementor-polylang/).

== Installation ==
1. Téléchargez le dossier du plugin dans `/wp-content/plugins/` ou installez via l'écran Plugins de WordPress.
2. Activez le plugin via le menu « Extensions » dans WordPress.
3. Configurez vos langues avec l'une de ces options :
   - **Intégré (Recommandé) :** Utilisez le système de langues intégré du plugin — aucun plugin supplémentaire nécessaire
   - **Polylang :** Allez dans Langues → onglet Langues → Ajouter des langues
   - **WPML :** Allez dans WPML → Langues → Ajouter des langues et configurer
4. Accédez à la page du plugin AI Translator.
5. Commencez à traduire vos pages Elementor !

== Frequently Asked Questions ==
= Combien de mots puis-je traduire gratuitement ? =
La version gratuite inclut 1 800 mots par semaine. Après avoir atteint la limite, il y a une période de récupération hebdomadaire.

= Elementor Pro est-il requis ? =
Non. Cela fonctionne avec Elementor gratuit et Elementor Pro.

= Polylang Pro est-il requis ? =
Non. Il supporte à la fois Polylang gratuit et Polylang Pro.

= Quel fournisseur d'IA est utilisé ? =
OpenAI via notre API de traduction sécurisée. Nous gérons toute la communication API pour assurer sécurité et fiabilité.

= Cela modifiera-t-il mon contenu existant ? =
Non. Les traductions sont appliquées aux copies traduites dans la langue cible. Votre contenu original reste inchangé.

= Que se passe-t-il quand j'atteins ma limite de mots ? =
Vous devrez attendre la réinitialisation hebdomadaire, ou passer à un plan PRO pour des limites plus élevées sans périodes d'attente.

= Comment puis-je vérifier combien de mots il me reste ? =
Visitez AI Translator → Tableau de bord pour voir votre utilisation actuelle et les mots restants.

== Privacy & Data Collection ==

Ce plugin se connecte à notre API de traduction sur meeptech.com pour traiter les traductions et suivre l'utilisation.

= Quelles données sont collectées : =
✅ L'URL de votre site web (pour l'authentification du service et le suivi de l'utilisation)
