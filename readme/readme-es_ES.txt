== Description ==
Meep AI Translator es una solución de traducción con IA para WordPress. Traduce tus páginas de Elementor sin problemas con Polylang utilizando el avanzado motor de traducción de OpenAI.

**Características:**
– Traducción con un clic para páginas de Elementor
– Integración con Polylang (versiones gratuita y Pro compatibles)
– Traducciones impulsadas por OpenAI para resultados naturales y contextuales
– 1.800 palabras por semana incluidas gratis
– Interfaz de administración limpia sin interferencias de Elementor
– Panel de control con análisis de uso

**Cómo funciona:**
1. Selecciona tu página de Elementor
2. Elige el/los idioma(s) de destino
3. Haz clic en traducir - ¡la IA hace el resto!

Una versión PRO con límites de palabras más altos está disponible en [meeptech.com](https://meeptech.com/products/ai-translator-for-elementor-polylang/).

== Installation ==
1. Sube la carpeta del plugin a `/wp-content/plugins/` o instala a través de la pantalla de Plugins de WordPress.
2. Activa el plugin a través del menú 'Plugins' en WordPress.
3. Configura tus idiomas con una de estas opciones:
   - **Integrado (Recomendado):** Usa el sistema de idiomas integrado del plugin — no se necesitan plugins adicionales
   - **Polylang:** Ve a Idiomas → pestaña Idiomas → Añadir idiomas
   - **WPML:** Ve a WPML → Idiomas → Añadir idiomas y configurar
4. Navega a la página del plugin AI Translator.
5. ¡Comienza a traducir tus páginas de Elementor!

== Frequently Asked Questions ==
= ¿Cuántas palabras puedo traducir gratis? =
La versión gratuita incluye 1.800 palabras por semana. Después de alcanzar el límite, hay un período de espera semanal.

= ¿Se requiere Elementor Pro? =
No. Funciona con Elementor gratuito y Elementor Pro.

= ¿Se requiere Polylang Pro? =
No. Es compatible con Polylang gratuito y Polylang Pro.

= ¿Qué proveedor de IA se utiliza? =
OpenAI a través de nuestra API de traducción segura. Manejamos toda la comunicación de API para garantizar seguridad y fiabilidad.

= ¿Modificará esto mi contenido existente? =
No. Las traducciones se aplican a copias traducidas en el idioma de destino. Tu contenido original permanece sin cambios.

= ¿Qué pasa cuando alcanzo mi límite de palabras? =
Deberás esperar al reinicio semanal, o actualizar a un plan PRO para límites más altos sin períodos de espera.

= ¿Cómo puedo verificar cuántas palabras me quedan? =
Visita AI Translator → Panel de control para ver tu uso actual y palabras restantes.

== Privacy & Data Collection ==

Este plugin se conecta a nuestra API de traducción en meeptech.com para procesar traducciones y rastrear el uso.

= Qué datos se recopilan: =
✅ La URL de tu sitio web (para autenticación del servicio y seguimiento del uso)
✅ Recuentos de palabras y pares de idiomas (para aplicación de límites del plan)

= Qué datos NO se recopilan: =
❌ Tu contenido traducido no se almacena (solo se envía a OpenAI para procesamiento)
❌ Información personal o direcciones de email
❌ Datos de usuarios o visitantes
