== Description ==
AI Translator for Elementor and Polylang — це рішення для AI-перекладу в WordPress. Легко перекладайте сторінки Elementor за допомогою Polylang, використовуючи передовий двигун перекладу OpenAI.

**Можливості:**
– Переклад сторінок Elementor в один клік
– Інтеграція з Polylang (підтримка безкоштовної та Pro версій)
– Переклади на основі OpenAI для природних, контекстних результатів
– 1 800 слів на тиждень безкоштовно
– Чистий інтерфейс адміністратора
– Панель керування з аналітикою використання

**Як це працює:**
1. Виберіть сторінку Elementor
2. Виберіть цільову мову(и)
3. Натисніть перекласти — ШІ зробить все інше!

PRO версія зі збільшеними лімітами слів доступна на [meeptech.com](https://meeptech.com/products/ai-translator-for-elementor-polylang/).

== Installation ==
1. Завантажте папку плагіна в `/wp-content/plugins/` або встановіть через екран плагінів WordPress.
2. Активуйте плагін через меню «Плагіни» в WordPress.
3. Додайте потрібні мови в налаштуваннях Polylang (Мови → Мови).
4. Перейдіть на сторінку плагіна AI Translator.
5. Почніть перекладати сторінки Elementor!

== Frequently Asked Questions ==
= Скільки слів можна перекласти безкоштовно? =
Безкоштовна версія включає 1 800 слів на тиждень. Після досягнення ліміту потрібен тижневий період очікування.

= Чи потрібен Elementor Pro? =
Ні. Працює з безкоштовним Elementor та Elementor Pro.

= Чи потрібен Polylang Pro? =
Ні. Підтримує безкоштовний Polylang та Polylang Pro.

= Який AI-провайдер використовується? =
OpenAI через наш захищений API перекладу. Ми забезпечуємо безпеку та надійність усіх API-комунікацій.

= Чи змінить це мій існуючий контент? =
Ні. Переклади застосовуються до перекладених копій на цільовій мові. Ваш оригінальний контент залишається незмінним.

= Що відбувається при досягненні ліміту слів? =
Потрібно дочекатися щотижневого скидання або перейти на PRO план для збільшених лімітів без періодів очікування.

= Як перевірити залишок слів? =
Перейдіть в AI Translator → Панель керування для перегляду поточного використання та залишку слів.
