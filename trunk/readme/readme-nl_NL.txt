== Description ==
Meep AI Translator is een AI-vertalingsoplossing voor WordPress. Vertaal je Elementor-pagina's naadloos met Polylang met behulp van de geavanceerde vertaalengine van OpenAI.

**Functies:**
– Vertaling met één klik voor Elementor-pagina's
– Polylang-integratie (gratis en Pro versies ondersteund)
– OpenAI-aangedreven vertalingen voor natuurlijke, contextuele resultaten
– 1.800 woorden per week gratis inbegrepen
– Schone admin-interface zonder Elementor-interferentie
– Dashboard met gebruiksanalyse

**Hoe het werkt:**
1. Selecteer je Elementor-pagina
2. Kies de doeltaal/talen
3. Klik op vertalen - AI doet de rest!

Een PRO-versie met hogere woordlimieten is beschikbaar op [meeptech.com](https://meeptech.com/products/ai-translator-for-elementor-polylang/).

== Installation ==
1. Upload de plugin-map naar `/wp-content/plugins/` of installeer via het WordPress Plugins-scherm.
2. Activeer de plugin via het menu 'Plugins' in WordPress.
3. Stel je talen in met een van deze opties:
   - **Ingebouwd (Aanbevolen):** Gebruik het ingebouwde taalsysteem van de plugin — geen extra plugins nodig
   - **Polylang:** Ga naar Talen → Talen tab → Talen toevoegen
   - **WPML:** Ga naar WPML → Talen → Talen toevoegen en configureren
4. Navigeer naar de AI Translator plugin-pagina.
5. Begin met het vertalen van je Elementor-pagina's!

== Frequently Asked Questions ==
= Hoeveel woorden kan ik gratis vertalen? =
De gratis versie bevat 1.800 woorden per week. Na het bereiken van de limiet is er een wekelijkse afkoelperiode.

= Is Elementor Pro vereist? =
Nee. Het werkt met Elementor gratis en Elementor Pro.

= Is Polylang Pro vereist? =
Nee. Het ondersteunt zowel Polylang gratis als Polylang Pro.

= Welke AI-provider wordt gebruikt? =
OpenAI via onze beveiligde vertaal-API. Wij zorgen voor alle API-communicatie om veiligheid en betrouwbaarheid te garanderen.

= Zal dit mijn bestaande content wijzigen? =
Nee. Vertalingen worden toegepast op vertaalde kopieën in de doeltaal. Je originele content blijft ongewijzigd.

= Wat gebeurt er als ik mijn woordlimiet bereik? =
Je moet wachten op de wekelijkse reset, of upgraden naar een PRO-plan voor hogere limieten zonder wachttijden.

= Hoe kan ik controleren hoeveel woorden ik nog over heb? =
Bezoek AI Translator → Dashboard om je huidige gebruik en resterende woorden te zien.
