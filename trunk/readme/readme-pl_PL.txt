== Description ==
Meep AI Translator to rozwiązanie tłumaczenia AI dla WordPress. Tłumacz swoje strony Elementor bezproblemowo z Polylang, używając zaawansowanego silnika tłumaczeń OpenAI.

**Funkcje:**
– Tłumaczenie jednym kliknięciem dla stron Elementor
– Integracja z Polylang (obsługiwane wersje darmowe i Pro)
– Tłumaczenia napędzane przez OpenAI dla naturalnych, kontekstowych rezultatów
– 1800 słów tygodniowo w wersji bezpłatnej
– Czysty interfejs admina bez zakłóceń Elementora
– Panel z analityką użycia

**Jak to działa:**
1. Wybierz swoją stronę Elementor
2. Wybierz język(i) docelowy(e)
3. Kliknij tłumacz - AI zrobi resztę!

Wersja PRO z wyższymi limitami słów jest dostępna na [meeptech.com](https://meeptech.com/products/ai-translator-for-elementor-polylang/).

== Installation ==
1. Prześlij folder wtyczki do `/wp-content/plugins/` lub zainstaluj przez ekran Wtyczek WordPress.
2. Aktywuj wtyczkę przez menu „Wtyczki" w WordPress.
3. Skonfiguruj swoje języki za pomocą jednej z tych opcji:
   - **Wbudowany (Zalecany):** Użyj wbudowanego systemu językowego wtyczki — nie są potrzebne dodatkowe wtyczki
   - **Polylang:** Przejdź do Języki → zakładka Języki → Dodaj języki
   - **WPML:** Przejdź do WPML → Języki → Dodaj języki i skonfiguruj
4. Przejdź do strony wtyczki AI Translator.
5. Zacznij tłumaczyć swoje strony Elementor!

== Frequently Asked Questions ==
= Ile słów mogę przetłumaczyć za darmo? =
Wersja bezpłatna zawiera 1800 słów tygodniowo. Po osiągnięciu limitu jest tygodniowy okres oczekiwania.

= Czy wymagany jest Elementor Pro? =
Nie. Działa z Elementorem darmowym i Elementor Pro.

= Czy wymagany jest Polylang Pro? =
Nie. Obsługuje zarówno Polylang darmowy, jak i Polylang Pro.

= Jakiego dostawcy AI używacie? =
OpenAI przez nasze bezpieczne API tłumaczeń. Obsługujemy całą komunikację API, aby zapewnić bezpieczeństwo i niezawodność.

= Czy to zmodyfikuje moją istniejącą treść? =
Nie. Tłumaczenia są stosowane do przetłumaczonych kopii w języku docelowym. Twoja oryginalna treść pozostaje niezmieniona.

= Co się dzieje, gdy osiągnę limit słów? =
Musisz poczekać na cotygodniowy reset lub przejść na plan PRO dla wyższych limitów bez okresów oczekiwania.

= Jak sprawdzić ile słów mi zostało? =
Odwiedź AI Translator → Panel, aby zobaczyć aktualne użycie i pozostałe słowa.
